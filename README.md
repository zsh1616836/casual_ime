# 随意五笔输入法

`casual_ime` 是一个面向 Windows 的开源、免费、可定制五笔输入法，默认词库为86版五笔。

这是项目的初版，功能、兼容性和词库都还有不少可以改进的地方。它不是一个已经打磨完成的商业产品，而是一个认真把「五笔输入体验」当作核心问题来做的开源项目。欢迎使用、反馈问题，也欢迎提出对词库、候选排序和交互方式的意见；项目会根据实际使用情况持续优化。

## 当前状态

作者认为现实中的很多五笔输入法使用起来并不理想：

- 产品设计没有真正围绕五笔用户的输入习惯展开，编码、候选和上屏逻辑之间缺少协调；
- 词库常常沿用拼音输入法的思路，追求收录更多词语，却没有充分考虑五笔用户对编码确定性和输入节奏的要求；
- 词库并不是越大越好。候选越多，重码往往越严重；如果输入法没有认真处理重码，用户就不得不频繁看候选框、翻页和选词，五笔本来适合盲打的优势反而会被削弱。
- 有的输入法为了追求更大的词库和更多的候选，甚至会在输入编码时出现卡顿。

`casual_ime` 希望从这些问题出发，尝试建立一种更符合五笔使用方式的输入体验：词库服务于输入，候选服务于上屏，重码处理服务于连续输入，而不是单纯追求词条数量。

## 当前特点

- 基于 Windows TSF（Text Services Framework），支持 x86 和 x64 组件；
- 纯五笔候选和拼音辅助候选区别处理，完整五笔编码的候选保持优先；
- 四码只有一个纯五笔候选时，可直接上屏；
- 输入第五码时，可选择自动上屏当前首选候选，减少因重码造成的停顿；
- 候选排序支持固定词序、按最近输入排序、按输入次数排序；
- 可以记录候选使用情况，让常用选择逐渐更符合个人习惯；
- 支持添加自定义词、删除不需要的候选，以及将候选标记为生僻词；
- 可以选择是否显示生僻候选，并支持中文/英文模式、中文/英文标点、全角/半角等常用状态切换；
- 候选窗口和状态窗口独立运行，针对不同 Windows 文本输入场景处理候选窗口定位和宿主兼容性；
- 词库以源码和编译工具的形式放在仓库中，便于按自己的习惯调整和重新生成。

这些机制不能消除所有重码，也不应该承诺「永远不用选词」。它们的目标是：在可以确定上屏时尽量不打断输入，在确实存在歧义时让候选顺序和操作方式尽量可预测。


## 安装与使用

如果项目发布了安装包，建议从 GitHub 的 Releases 页面下载对应版本。安装后，在 Windows 的输入法设置中添加并切换到「随意五笔输入法」即可。

目前项目仍处于早期阶段，安装包、系统版本和具体应用程序之间可能存在兼容性差异。遇到候选窗口位置不正确、某些软件中无法输入、安装或注册失败等问题时，欢迎提交 Issue，并尽量附上：

- Windows 版本和系统架构；
- 出现问题的应用程序；
- 输入过程和预期结果；
- 可复现步骤，以及相关日志（注意删除个人输入内容）。

## 从源码构建

### 构建运行组件

构建环境：

- Windows；
- Visual Studio/MSVC；
- CMake 3.23 或更高版本。

在仓库根目录执行：

```powershell
cmake -S . -B build
cmake --build build --config Release
```

项目会构建输入法 DLL、后台 Broker 和词库工具。具体的注册和部署方式可参考 `ime/`、`broker/` 与 `installer/` 目录中的构建文件。

### 构建安装包

构建安装包还需要 Inno Setup 7：

```powershell
.\packaging\build-installer.ps1
```

生成的安装包和校验文件位于 `dist/`。如果 Inno Setup 没有安装在脚本能够自动找到的位置，可以通过 `ISCC` 环境变量指定 `ISCC.exe` 的完整路径。更多选项见 [`packaging/README.md`](packaging/README.md)。

## 定制词库

你可以通过以下方式定制输入体验：

- 在候选窗口中添加自定义词；
- 删除不希望再次出现的候选；
- 将低频或容易干扰输入的候选标记为生僻词；
- 修改 `word_dic/` 中的词库源文件，并使用 `dic/` 中的工具重新编译；
- 根据需要调整运行时配置，例如自动上屏、候选排序、生僻候选显示和界面字体大小。

运行时配置和用户词库默认位于 `%LOCALAPPDATA%\ZIme`。基础词库和用户词库分开保存，便于升级程序时保留个人设置。
