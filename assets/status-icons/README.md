# Runtime Status Icons

This directory is the canonical source for the eight status-window images:

- `main.png`: product mark
- `cn.png` and `en.png`: Chinese/English mode
- `cn_pun.png` and `en_pun.png`: Chinese/English punctuation
- `full_width.png` and `half_width.png`: full/half width
- `settings.png`: feature menu

The installer stages these files under its `ico` directory. Do not add backup
or experimental images here; keep the set synchronized with
`packaging/release-assets.json`.
